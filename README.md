# Portofolio Arif Rohman Hakim

Portofolio web modern, responsif, dan interaktif yang dibangun berdasarkan profil GitHub [@arifrohmanhakim](https://github.com/arifrohmanhakim).

## 🚀 Fitur Utama

- **Statistik GitHub Real-time**: Mengambil data repositori publik, total stars, gists, dan followers secara dinamis via GitHub API dengan fallback offline yang aman.
- **Showcase Proyek Unggulan**:
  - [Payaman OS](https://payamanos.vercel.app) (Retro 1-bit Web Operating System terinspirasi Classic Mac OS)
  - Animalpedia Kids (Aplikasi edukasi interaktif anak-anak)
  - Doit Digital Wallet (Aplikasi mobile finansial dengan React Native)
  - react-native-web-maps (Library open source React Native for Web)
  - Sinau AI Ebook, React Easy Query Builder, Ruangsemu, dan API Central Gateway.
- **Filter Kategori Dinamis**: Filter proyek berdasarkan Web Applications, Mobile (React Native), Libraries & Tools, serta Backend.
- **Dark & Light Mode**: Dukungan mode gelap dan terang otomatis mengikuti sistem OS dengan penyimpanan preferensi lokal (`localStorage`).
- **Desain Modern & Clean**: Tipografi modern (*Plus Jakarta Sans* & *JetBrains Mono*), glassmorphism, dan micro-interactions yang halus.

## 🛠️ Menjalankan Proyek

```bash
# Jalankan server pengembangan
npm run dev

# Membangun bundle produksi
npm run build

# Menjalankan preview produksi
npm run preview
```
